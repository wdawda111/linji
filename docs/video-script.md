# 5 分钟演示视频讲稿（邻集）

> 建议录制方式：手机模拟器 / 浏览器 DevTools 手机视口（390×844）录屏为主，切桌面视口展示响应式；提前 `npm run dev`，数据库带种子数据。
> 每段结束看一眼时间轴，总体控制在 5 分钟内。

## 0:00 – 0:30 开场：封面 + 痛点

（画面：停在暗色封面 `/`，让光斑漂浮和阶梯入场演完一遍）

> “小区微信群里，转让消息刷得太快，东西还没被看到就沉了。这是我做的「邻集」——封面上的三个数字和下面的物品全是小区的真实流转数据。点‘进入邻集’。”

（点“进入邻集”进入 `/discover` 信息流，衔接原稿 0:30 的信息流演示）

> "我刚搬到一个新城市，小区微信群里天天有婴儿车、电磁炉、绘本的转让消息——但群消息刷得太快，东西还没被人看到就沉了。想出闲置的人不知道怎么定价，想买的人不知道还在不在，双方还要私聊约时间。
>
> 所以我做了「邻集」——一个专门给小区内部用的闲置流转工具。熟人社区不需要信用体系，楼上楼下不需要快递，最核心只有一件事：**让闲置物品在沉没之前被看到**。"

（画面：停在首页信息流，鼠标圈一下卡片上的"刚上架"徽章）

## 0:30 – 1:30 首页信息流：新鲜度是第一优先级

- 演示卡片流：绿色呼吸点"刚上架"（24h 内）→ 琥珀色"新上架"（72h 内）→ 灰色"已上架 X 天"。
- 点一下"🎁 免费送"筛选 → 只看免费；再切"🏷️ 标价"。
- 搜索框输入"绘本" → 实时过滤。
- 切到"已送出"页签 → 归档物品可查看（灰度图 + "已送出"标记），但不可操作。

> "信息流严格按新鲜度排序，24 小时内刚上架的物品有呼吸点提醒——这就是产品命题的直接表达。筛选、搜索、归档都在首屏一步之内。"

## 1:30 – 2:40 发布 + LLM 三件套（重点段落）

点"发布闲置"：

1. 输入名称"九成新戴森吸尘器 V8"，随便写一句粗糙描述。
2. 点 **✨ AI 智能定价** → 返回定价区间 + 理由，自动填入建议价。
3. 点 **✨ AI 润色** → 文案以"打字机"效果逐字写入，像 AI 在你面前现场书写（强调"可继续编辑"）。
4. 选一张占位图（或上传实拍），选成色，选交易方式 → 发布。
5. 自动跳转详情页。

> “LLM 默认接 Z.ai 的 GLM，走 OpenAI 兼容协议，Provider 在 .env 里可配置；切到 DeepSeek 不用改业务代码。没有 Key 或调用失败时自动降级成内置 Mock，界面会标注实际来源，保证演示不中断。”

## 2:40 – 3:40 意向表达与沟通：双视角演示

（右上角头像 → 退出登录 → 用另一个演示账号登录——展示真实账号体系与双视角）

- 切到"浏览者"（如大熊）：点"我想要" → 心形点亮、数字 +1（乐观更新）→ 留言板问"还在吗？"发送。
- 切回"发布者"（林老师）：详情页"谁想要"出现名单；点对方留言下的"回复"可**楼层内回复**（显示"回复 @某人"）；对常见提问点 **✨ AI 回复建议** → 自动生成回复以打字机效果填入输入框，可编辑后发送；留言板有"楼主"徽章。
- 点 **🤝 标记已送出** → 弹窗里从"想要"名单中选接收人 → 确认。

> "交易确认后物品自动归档但保留记录，成交时间被系统记录——这直接喂给数据看板。"

## 3:40 – 4:20 数据看板

切到"看板"页：

- 三个数字：本月发布 / 本月成交 / 当前在售。
- **近 14 天流转趋势**柱状图：绿柱是每天新发布，蓝柱是成交——一眼看出小区活跃节奏。
- **最快被领走的物品**：刚送出的吸尘器 0.1 小时上榜（发布→标记送出的真实耗时）。
- **最想要的物品**：猫爬架 4 人想要但未成交——提示发布者该降价或免费送了。

> "看板不是摆设：'最快被领走'度量流转效率，'最想要'暴露供需缺口，趋势图反映社区活跃度，都是直接从业务动作里长出来的指标。"

## 4:20 – 5:00 技术架构 + 总结（对着 README 讲）

- 技术栈：Next.js 16 + React 19 + TypeScript + Tailwind v4 前端；REST API 层 + Prisma + SQLite 后端；Z.ai GLM。
- 强调**前后端解耦**：前端只认 `/api/*` 的 JSON 协议，查询校验集中在 `src/lib`，换移动端 App 也能直接复用。
- 数据库四张表：User / Item / Want / Comment；"想要"用唯一约束保证幂等；成交用状态字段 + 时间戳表达，**不做过度设计**（交易在线下，线上只留轻记录）。
- 收尾一句：

> "这个项目从建库到 LLM 接入都是我用 AI Coding 工具在 24 小时内完成的：我的工作是把题目翻译成清晰的数据模型和产品取舍，再让 AI 快速落地成可运行、拿得出手的东西。谢谢观看。"

## 录制注意事项

- 移动视口录制主流程，最后 30 秒切桌面视口展示响应式（4 列网格）。
- 如已配置 API Key，演示时 toast 会显示实际 Provider（GLM / DeepSeek）；Mock 模式显示“内置模拟”，讲稿已兼容两种情况。
- 录屏前跑一遍 `npm run db:seed -- --force` 重置演示数据，保证"刚上架"徽章和看板数字好看。
