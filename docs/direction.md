# Direction contract（开发用，非交付物）

## THESIS
用户钉选紫粉白三色（AuraUI Hero 结构 + 紫粉配色）：白纸底（微紫调）+ 紫/粉漂浮光斑 + 白玻璃导航，紫渐变药丸是唯一主行动色，粉色呼吸点是产品签名时刻。拒绝的类别默认：二手交易 = 彩色卡片瀑布 + 促销徽章；暗夜翡翠（上一版，用户否决）；ChatGPT 亮单色（更早，用户否决）。

## OWN-WORLD
#fbfafe 白纸底 + 白玻璃侧栏；发丝线 violet 调；唯一渐变药丸 violet-600→fuchsia-500；玻璃面用于封面导航/徽章；渐变强调字只在封面主标题出现一次；Phosphor 图标；占位图浅色低饱和 hue 渐变。

## STORY
封面用真实统计与一件最新在售物品证明“小区在流转”（不虚构数字）；进入邻集 → 发现页卡片信息流；发布 = 紫粉渐变主行动；看板 = 社区脉搏。

## FIRST VIEWPORT
封面：玻璃导航（logo/发现/看板/进入邻集）→ 场景徽章 → 直接痛点标题“别让好东西，沉在群聊里”→ 副文案 → “看看邻居在出什么”+“发布一件闲置”双 CTA → 真实三格统计 → 最新物品主预览与三步流转说明。背景只保留克制光斑，零额外动画依赖。

## FORM
